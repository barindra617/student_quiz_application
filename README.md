# 🎓 Student Quiz App

A fun and educational Android quiz app built with Java 
in Android Studio. Test your knowledge across 3 exciting 
categories with 20 questions each!

## 📚 Categories
- 💻 Computers — Test your tech knowledge
- 🚗 Cars — How well do you know cars?
- 🎌 Anime — Prove you are a true anime fan!

## ✨ Features
- 3 fun categories to choose from
- 20 multiple choice questions per category
- 4 options per question
- Live score tracking
- Progress bar showing your progress
- Final score screen with performance message
- Play again button to retry

## 🛠️ Built With
- Java
- Android Studio
- XML for UI design

## 📱 How To Use
1. Open the app
2. Pick a category
3. Answer 20 questions
4. See your final score!

## 🏆 Score Messages
- 18-20 → Outstanding!
- 14-17 → Great job!
- 10-13 → Not bad!
- 0-9   → Keep studying!
